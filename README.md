# ⚡ vAyum - Blazingly Lazy. Witty. Modular.

**vAyum** is my Neovim config/(distro... not technically) - fast, minimal, plugin-powered, and built for devs who like their rice crispy and their editor snappy.

## 🚀 Installation

> [!CAUTION]
> Make sure to have a backup of your previous dotfiles!

```bash
git clone https://github.com/ayushmanofficial/vAyum ~/.config/nvim
```

---

## ⚙️ Requirements

- Neovim 0.10+ (not tested on older, won't test either)
- A real terminal (truecolor gang)
- Git
- `lazygit` (optional, planned, you can use the TUI rn.)

---

## ✨ Features

- Blazingly fast (because Neovim is)
- Fully plugin-driven - nothing weird, just Lua and vibes
- Loads of Folke plugins (Powered By Folke Industries™)
- LSP + CMP + Snippets baked in
- Telescope for all ~Ctrl+P~ Space+SF dreams
- Theming with `base16-nvim` (so that you have, a lot of colorschemes!)
- Transparent mode, if you like pretending your terminal's invisible
- Modular as heck - easy to rip, tweak, or break
